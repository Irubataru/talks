# 2023 The Rust programming language

* Title: The Rust programming language
* Event: Internal seminar at SINTEF Optimization
* Date: 2023-08-29
* Made for [presentterm](https://github.com/mfontanini/presenterm)

This is a short overview of the Rust programming language where I show the
things I think make Rust interesting. It's strong memory safety guarantees have
some real impact on how you approach problems, and to me that changes the code
enough to make it different from other mainstream procedural/OO languages.
